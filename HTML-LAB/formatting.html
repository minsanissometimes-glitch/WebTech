HTML Text Formatting

HTML stands for HyperText Markup Language.

HTML Formatting Tags

<b> - Makes text bold.

<strong> - Indicates that the text is important.

<i> - Displays text in italic style.

<em> - Emphasizes text, usually displayed in italic.

<u> - Underlines the text.

<mark> - Highlights text.

<small> - Displays text in a smaller size.

<del> - Represents deleted or removed text.

<ins> - Represents inserted or added text.

<sub> - Displays text as subscript.

<sup> - Displays text as superscript.
